# Jingang Zhou

Personal academic homepage.

## Edit

- `profile.js`: biography, education, news, publications, and internships.
- `style.css`: page styling.
- `assets/`: images and fonts.

## Publish

This repository is prepared for GitHub Pages at `https://gyanchow.github.io/`.
In Settings → Pages, select **Deploy from a branch**, branch **main**, folder **/(root)**.

Layout inspired by [Haiyang Guo](https://ghy0501.github.io/guohaiyang0501.github.io/) and the [Jon Barron website template](https://github.com/jonbarron/jonbarron_website).
